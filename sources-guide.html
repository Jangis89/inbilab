소스 지도 🗺️

🔒 이 페이지는 아직 비공개(관리자 전용)입니다. 공개하려면 작업실에서 스위치를 켜세요.

쇼츠 재료를 저작권 걱정 없이 구할 수 있는 곳을 한 페이지에 모았습니다. 어느 사이트에서 무엇을 얻고, 무엇을 조심해야 하는지 신호등으로 확인하세요.

🟢 자유 사용 상업용(수익 창출 영상)에 자유롭게 사용 가능  ·  🟡 조건 확인 출처 표기 또는 이용 조건 확인 후 사용  ·  🔴 주의 잘못 쓰면 저작권 문제가 될 수 있음

1. 무료 스톡 영상 🎞️

쇼츠 배경·삽입용 영상 클립. 아래 사이트는 모두 회원가입 없이 다운로드할 수 있고, 수익 창출 영상에도 쓸 수 있습니다.
Pexels 동영상🟢 자유 사용
가장 추천. 양이 많고 품질이 높으며 한국어 검색도 됩니다. 출처 표기는 의무가 아니지만 해 주면 좋습니다.
💡 세로(9:16) 영상만 보려면 검색 후 필터에서 "세로 방향"을 선택하세요. 인비랩의 제작 설계도·대본의 [미리보기] 버튼도 Pexels에서 찾아 줍니다.
Pixabay 동영상🟢 자유 사용
Pexels와 함께 쓰는 2번 창고. 자연·풍경·배경 영상이 특히 많습니다.
Mixkit🟢 자유 사용
감각적인 연출 영상이 많습니다. 영어 검색만 가능 (설계도의 영어 검색어를 복사해 쓰세요).
Coverr🟢 자유 사용
일상·라이프스타일 클립 위주. 영어 검색.

2. 무료 이미지 🖼️

정지 이미지 + 줌인 효과는 쇼츠의 기본기입니다.
Pexels 사진 · Pixabay🟢 자유 사용
영상과 같은 계정·같은 규칙으로 사진도 받을 수 있습니다.
Unsplash🟢 자유 사용
고품질 감성 사진. 상업 사용 가능, 출처 표기 권장.

3. 음악 · 효과음 🎵

배경음악은 저작권 신고가 가장 많이 걸리는 부분입니다. 반드시 아래처럼 안전한 곳에서만 받으세요.
유튜브 스튜디오 — 오디오 보관함🟢 자유 사용
유튜브 스튜디오 왼쪽 메뉴 "오디오 보관함". 유튜브에 올리는 영상이라면 가장 안전한 선택입니다.
💡 일부 곡은 "저작자 표시 필요"로 표시됩니다 — 그 곡을 쓰면 영상 설명란에 곡 정보를 적어 주세요.
Pixabay 음악·효과음🟢 자유 사용
배경음악과 "띠링", "휙" 같은 효과음까지. 유튜브 밖(교육 자료 등)에 써도 됩니다.
공유마당 (한국저작권위원회)🟡 조건 확인
기증·만료 저작물 모음. 자료마다 이용 조건(CC 표시)이 다르니 각 자료의 라이선스 표시를 확인하세요.

4. 공공 소스 (정부 · 공공기관) 🏛️

뉴스·정보성 쇼츠에서 힘을 발휘하는 재료 창고. "공공누리 제1유형"이면 출처만 적고 자유롭게 쓸 수 있습니다.
공공누리🟡 조건 확인
정부·지자체·공공기관 사진·영상 통합 검색. 제1유형(출처 표시)은 상업 사용 가능. 제3·4유형은 변경·상업 제한이 있으니 유형 표시를 꼭 확인하세요.
💡 출처 표기 예: "출처: 문화체육관광부, 공공누리 제1유형"
KTV 국민방송🟡 조건 확인
정부 영상 기록(대통령 일정, 정책 발표 등). 상당수가 공공누리 유형으로 제공 — 각 영상의 표시를 확인.
국가기록원🟡 조건 확인
옛날 한국 영상·사진 (역사 쇼츠 재료). 기록물마다 이용 조건 확인.
NASA 이미지·영상 라이브러리🟢 자유 사용
우주 관련 재료는 여기가 끝판왕. 미국 정부 저작물이라 대부분 자유롭게 사용 가능 (NASA 로고 자체는 사용 금지).

5. 게임 화면 🎮

게임 쇼츠는 "직접 플레이 화면 녹화"가 기본입니다. 대부분의 게임사는 개인 창작자의 플레이 영상 수익화를 허용하지만, 회사마다 정책이 다릅니다.
직접 녹화 방법🟡 조건 확인
PC: 윈도우 기본 게임바(Win+G) 또는 무료 프로그램 OBS Studio. 모바일: 아이폰 화면 기록 / 갤럭시 화면 녹화.
💡 쓰기 전에 "게임이름 + 크리에이터 정책"으로 검색해서 허용 여부를 확인하세요. 넥슨·라이엇·마인크래프트 등 대부분 허용, 닌텐도는 별도 규정이 있어 주의.
남의 게임 영상 재사용🔴 주의
다른 유튜버의 플레이 영상을 그대로 잘라 쓰는 것은 저작권 침해입니다. 반드시 본인이 녹화하거나, 원작자 허락을 받으세요.

6. 뉴스 · 커뮤니티 캡처 📰

이슈 쇼츠의 단골 재료지만, 가장 조심해야 하는 영역이기도 합니다.
뉴스 기사 화면 캡처🔴 주의
기사 제목·헤드라인 일부를 근거 자료로 잠깐 보여주는 것은 통상 인용 범위로 봅니다. 하지만 기사 본문을 통째로 읽어주거나, 언론사 사진·영상을 그대로 쓰는 것은 침해 위험이 큽니다.
💡 안전 수칙: ① 화면에 2~3초만 ② 출처(언론사명) 표시 ③ 내용은 내 말로 재구성 ④ 사진은 캡처 대신 무료 스톡으로 대체
커뮤니티 글 캡처🔴 주의
글쓴이 아이디·프로필 사진 등 개인정보는 반드시 모자이크. 사연을 소재로 쓸 때는 각색해서 사용하세요.
⚠️ 영화·드라마·방송·스포츠 중계 장면은 "짧게 쓰면 괜찮다"는 속설과 달리 신고·수익 제한의 단골 원인입니다. 리뷰·비평 목적이 아니라면 쓰지 않는 것을 기본으로 하세요.

7. AI로 만들기 🎨

구할 수 없는 장면은 AI로 직접 만드는 것이 요즘 방식입니다. 제작 설계도가 "AI 생성 가능" 장면에 영어 프롬프트를 만들어 주니, 복사해서 붙여넣기만 하면 됩니다.
빙 이미지 크리에이터🟡 조건 확인
마이크로소프트 계정만 있으면 무료. 프롬프트를 붙여넣으면 이미지 4장 생성.
캔바 (Canva)🟡 조건 확인
텍스트 카드·타이틀 디자인 + AI 이미지 생성까지. 무료 요소만 쓰면 상업 사용 가능 (왕관 표시는 유료).
AI 생성물 공통 주의🟡 조건 확인
실존 인물·브랜드 로고·캐릭터를 생성해 쓰는 것은 위험합니다. 배경·사물·분위기 컷으로 활용하세요.

기억할 것 3가지 ✅

1. 재료는 🟢 사이트 + 직접 촬영/녹화 + AI 생성 이 세 가지로만 채우면 저작권 걱정이 없습니다.
2. 남의 영상을 다운로드해서 재사용하는 것이 가장 위험합니다 — 인비랩 도구들이 링크만 주는 이유입니다.
3. 헷갈리면 소스 창고에서 다른 수강생들이 검증한 소스를 찾아보세요.
