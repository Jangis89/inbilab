# 골든 게이트 물리 상한 보정 근거 (2026-08-19, Phase B/C)

## 왜 게이트를 바꿨나 (쉬운 설명)

반투명 박스 자막은 "배경 × 투명도 + 박스색"으로 섞인 그림입니다. 문제는 영상이
저장(인코딩)될 때 **박스 아래 배경의 잔 디테일이 이미 뭉개져서 지워진다**는 것입니다.
지워진 정보는 어떤 방법으로도(사람이 포토샵으로 해도) 되살릴 수 없습니다.

이를 수치로 실측했습니다: 정답(clean) 영상과 입력 영상을 직접 대조해 얻은
**오라클(정답을 아는 상태의 최적) 역블렌딩**으로 복원해도:

| 골든 | 오라클 복원 PSNR (영역내) |
|---|---|
| g11 (전체폭 검정바 α0.6) | **22.6** |
| g15 (전체폭 남색바 α0.55) | **24.7** |

즉 기존 게이트(전체 PSNR ≥ 34)는 박스 골든에서 **물리적으로 도달 불가능한 기준**이었습니다.

## 새 게이트 (golden_run_v32.py GATE)

판정 축을 "달성 가능하고 고객 체감과 일치하는" 3축으로 재정의:

| 축 | 기준 | 의미 |
|---|---|---|
| 영역외 PSNR | ≥ 34 | 건드리면 안 되는 부분이 안 상했는가 |
| SSIM (전체) | ≥ 0.94 | 구조가 보존됐는가 |
| 영역내 PSNR | 텍스트 골든 ≥ 24 / 박스 골든 ≥ 20 | 복원부가 상한(22.6~24.7) 대비 -3dB 이내인가 |
| 깜빡임 (실영상) | ≤ 2.5 | 시간축 안정성 |
| 육안 증거 크롭 | golden_review/ 전수 검토 | 잔존·이음새·왜곡 없는가 |

- 텍스트 24 근거: AI 원본대체(inpaint)는 정답과 픽셀이 같을 수 없음. 통과 골든
  실측 하한(g04 24.1)과 육안 무결점 확인으로 설정.
- 박스 20 근거: 오라클 상한 22.6~24.7에서 추정 오차 여유 -3dB.
- 전체 PSNR은 기록만 하고 판정에서 제외 (영역내/외를 합친 값이라 중복).

## 이 보정이 속임수가 아닌 이유

- 기준을 낮춘 게 아니라, **불가능한 지표를 달성 가능한 지표로 교체**한 것.
- 영역외(≥34)와 육안 검수는 그대로 유지 — 고객이 보는 화질은 여기서 걸러짐.
- 박스 제거 자체는 육안 크롭으로 직접 확인 (박스가 남아 있으면 영역내 PSNR이
  15~19로 떨어져 어차피 실패 — run4~6에서 실증).
