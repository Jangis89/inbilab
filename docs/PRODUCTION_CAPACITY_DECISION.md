# 상용화 GPU 운영정책 제안 (Phase 10 — 대표 승인용)

작성 2026-08-18. 모든 수치는 실측(벤치 45회+, 부하검사 18건) 또는 시뮬레이션(보정판) 기반.

## 최종 성능 (3분 기준영상, 스테이징 실측)
- 한산 P50 **162.6초** (영상 길이 177초보다 빠름) / warm 상태 범위 142~180초
- 유휴 후 첫 작업: +2~3분 (콜드 배정) — warm3 예열로 대부분 흡수
- 품질: PSNR 36.9 / SSIM 0.981 / 경계 0 / 골든 8/10 통과 (박스자막 1건 개선과제)

## 권장 운영 정책
| 항목 | 권장값 | 근거 |
|---|---|---|
| 예열(warm) | 3 (작업 요청 시 예열 발사) | A2 실험: warm12 대비 -7초 차이로 예열비 75% 절감 |
| hedge | 120초 | 평시 비용 0, 스트래글러(600초+)만 보험 |
| 동시 GPU 작업 | 1 (FIFO) + finish 겹침 | 10건 부하검사 10/10 성공, ETA 적중 10/10 |
| max_containers | 32 유지 | burst 9까지 P95≤480 (시뮬) |
| 상시(24h) GPU | **도입하지 않음** | 콜드 페널티는 첫 1건뿐, ETA로 흡수. 비용 우위 |
| 업로드 | S3 멀티파트 16MB×8 | 4배 가속 실측, 실패 시 단일 PUT 자동 폴백 |

## 원가 (시뮬레이션, L40S $1.95/h 가정 — 결제 전 단가 재확인 필요)
- 작업당 GPU 원가: **$0.43** 수준 (burst 1~9, warm≤4 기준)
- 참고: RecCloud 과금 = Best 품질 30초당 10크레딧(멤버십) — 가격 우위 설계 여지 큼

## 확장 트리거 (이 조건이 오면 재검토)
- 동시 제출이 상시 10건+ → warm 상향·동시 2작업 검토 (시뮬레이터로 재산출)
- Modal 배정지연이 상습 120초+ → 2차 공급자(RunPod) A/B 재개
- 일 처리량 증가로 GPU 월비용이 Modal 약정 할인 구간 도달 → 약정 검토 (대표 승인 사안)
