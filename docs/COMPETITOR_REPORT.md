# 경쟁사 동일영상 직접 측정 결과 (Phase 5, 2026-08-18)

원칙 준수: 결제·카드등록·계정생성 없이 진행 (로그인은 대표가 RecCloud 1곳만 직접 수행).

## 핵심 발견
1. **5개 전부 '무료로 전체 영상 처리'가 불가능** — 유료 크레딧/구독 또는 로그인 장벽.
2. RecCloud·HitPaw는 지울 영역을 **사용자가 직접 박스로 지정**해야 함 — inbilab의 전자동 감지는 명확한 UX 우위.
3. Vmake만 자동 Subtitle 모드 보유. 5초 처리 19초 → 단순 환산 시 3분 영상 ≈ 11분+ (추측; 서버 병렬화 가능성 있어 실제는 다를 수 있음). V32(3분 영상 2.7분)가 우위일 가능성 높으나 유료 장벽으로 실측 불가.
4. 가격 구조: RecCloud는 Best 품질 30초당 10크레딧(멤버십 구매 필요) — 분당 과금형. 우리 원가(작업당 GPU 실측 $0.41~0.76 시뮬레이션)와 비교해 가격 설계 여지 큼.

## 미완 항목 (사유)
- UnWatermark·SubEasy·HitPaw 실제 처리시간: 결제·계정생성 금지 원칙으로 중단.
  대표가 원하면 각 사이트 로그인 후 이어서 측정 가능 (결제는 여전히 금지선).
