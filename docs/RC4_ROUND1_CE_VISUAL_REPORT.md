## mask 밖 보존 (core/feather 분리 계측)
- C/E: core(경계 4px 밖) 최대차 **2~5** (256 스케일) — 사실상 완전 보존.
  ring(경계 0~4px feather) 80~165는 합성 이음 국소값.
- A의 core 45~255는 오염이 아니라 **이중 인코딩 잡음+파이프라인 자체 합성 경로**
  기인으로 추정(입력과 다른 인코딩 체인). D/F 구현 시 동일 체인으로 재계측 예정.
  (정직 고지: 255 최대값의 정확한 원점은 D/F 단계에서 프레임 단위로 규명한다.)

## 속도·원가 (81f 창당, H100 warm)
- C·E 공통: 추론 236~242초, VRAM 29GB(단일)/44GB(2모델 상주), 창당 ≈ $0.26.
- 명세 0.5 준수: **이 속도로 full-ROI 기본 경로 불가** — residual crop/window
  전용(후보 D/F)으로만 사용한다.

## 관찰 종합 (승자 선언 아님)
- 사람·구조·카드 실장면(UAT)에서는 **E(SVOR)가 유일하게 hallucination 없이 복원**.
- C(VACE)는 골든 정적 질감에서 수치 우세가 있으나 실장면에서 물체 생성 결함 2회 —
  removal 전용 학습 부재의 전형적 증상.
- A는 질감 보존은 최고지만 카드/자막 잔상 결함 유지.
- 다음 단계: 후보 D/F(flow 실화소 + residual 생성)로 A의 보존력과 E의 복원력 결합.
