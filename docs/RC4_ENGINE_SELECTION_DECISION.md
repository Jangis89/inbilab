## 2. 왜 선택했는가 — 명세 §11.1 우선순위대로

### 1순위. 대표 육안 품질
- **uat01_t154(반투명 자막, 두 시점 확인)**: F 잔상 없음 / D 블록형 자국 /
  C 없던 흰 접시 생성(환각) / E 잔상 없음.
- **uat02_t92_112(흰 카드 자막)**: E와 Vmake만 깨끗. A·C·D·F는 글자 자국 잔존,
  특히 C는 카드가 거의 그대로.
- → 두 유형을 한 엔진으로 못 덮는다는 것이 육안으로 확정. **F+E 이원 구성**의 근거.

### 2순위. 사람·동물·구조 보존
- uat01_t154는 사람 다리·개·기와가 겹치는 구간. F는 이 구간에서 구조 손상 없이
  바닥을 복원(육안). C만 구조적 환각(접시) 발생 → C 탈락 사유.
- mask 밖 보존: 생성계 후보 전부 out_core 2~5로 양호. **A만 45~255**로 원본
  훼손 — 현행 엔진의 구조적 약점(§11.2 "mask 밖 오염"에 해당).

### 3순위. 시간축 안정성 (PROVE RC-T, 11구간 평균순위)
D 2.09 < F 2.82 < E 2.91 < C 3.09 < A 4.09

### 4순위. 공간적 자연스러움 (PROVE RC-S, 11구간 평균순위)
D 1.73 < F 1.91 < A 2.55 < C 3.91 < E 4.91

### 5순위. 새 영상 일반화
- 11개 구간(골든 5 + UAT 6, 세 편의 서로 다른 실제 고객 영상)에서 F가 상위권을
  일관 유지. **단, 진짜 일반화 판정은 §14 blind holdout 20종 첫 개봉에서 한다.**

### 6순위. 처리속도
| 후보 | 81프레임 창당 | 판정 |
|---|---|---|
| F | **10~126초(평균 21.0초)** | 상용 가능 |
| E | 230~242초 | 전체 적용 불가 → 국소 heavy만 |

### 7순위. 실패율
P6 v4 재생성 11/11, PROVE 60/60, 글자잔상 60/60, steps A/B 3런 — **전부 fail=0**.

### 8순위. 비용 (H100 $0.001097/초 실측 단가)
- F: 창당 약 **$0.023**
- E: 창당 약 **$0.26** (11배) → 사용률을 낮게 유지해야 하는 이유

## 3. 왜 탈락시켰는가

### C (순정 VACE-1.3B 전체창) — 탈락
| 항목 | 근거 |
|---|---|
| 카드 ghost | uat02_t92_112 card_res **0.936** (거의 그대로 남음) → §11.2 필수 탈락 |
| 구조 환각 | uat01_t154에서 원본에 없는 흰 접시 생성 |
| 공간 자연스러움 | RC-S 평균순위 3.91 (하위) |
| 속도 | 전체창 방식이라 E와 동일한 속도 문제 |
→ **품질·안정성 어느 축에서도 F/E를 대체할 이유가 없다.**

### D (순정 VACE-1.3B residual) — 탈락(예비 보존)
| 항목 | 근거 |
|---|---|
| 읽히는 잔상 | uat01_t154 육안에서 블록형 자국 잔존(두 시점 재현) → §11.2 필수 탈락 |
| 글자잔상 지표 | 종합 3.09로 F(2.45)·E(2.36)에 열세 |
| 카드 | card_res 0.828 — F와 마찬가지로 실패 |
| 장점 | PROVE 종합 1위(6.91), 순정 VACE라 **라이선스 체인이 더 단순** |
→ **탈락하되 예비로 보존.** F가 §13/§14에서 문제를 보이면 대체 후보로 재검토.
   (PROVE 상위인데 탈락시키는 이유: PROVE는 읽히는 글자잔상을 못 잡는다는 것을
    이번에 실측으로 확인했고, 명세 우선순위 1위는 육안이다.)

## 7. Known limitations (숨기지 않고 기록)

1. **카드형 자막을 기본 경로(F)가 못 지운다.** heavy(E)로 우회하지만, E는 11배
   비싸고 느리다. 근본 해결은 카드 un-blend 강화(§6.5 경로)로 남아 있다.
2. **격자·반복패턴(g28)은 모든 후보가 약하다.** 최종 후보에서도 실패로 판정되면
   §10 specialist를 재개해야 한다.
3. **PROVE는 읽히는 글자잔상·카드 잔존을 감지하지 못한다.** 그래서 자체 제작한
   글자잔상·카드 지표를 병행한다. 이 두 지표는 이번에 만든 것이라 외부 검증이 없다.
4. **card_res 지표는 원본에 실제 카드가 있는 구간에서만 유효**하다(값 1 초과는
   해석 불가). 현재 신뢰 구간은 uat02_t92_112 하나뿐이며 육안 교차확인으로 보강했다.
5. **Vmake 비교는 UAT 5구간뿐**이다(uat03용 Vmake 원본 없음).
   그 5구간에서 RC-S는 우리 D/F가 전부 우세, **카드 구간은 Vmake가 우세**.
6. **일반화 미검증**: blind holdout 20종은 아직 봉인 상태(§14).
7. **원본 24시간 정리 정책**으로 생성용 원본이 사라질 수 있다(INC-2026-08-22-A).
   `storagels` 액션으로 복구 가능하나, 파이프라인 자동화는 미적용.
