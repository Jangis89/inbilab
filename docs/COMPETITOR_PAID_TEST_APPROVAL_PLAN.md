## 측정 프로토콜 (승인 후 제가 수행)

1. 동일 원본(기준 177초 실영상 + 골든 박스자막 클립 2종)을 각 서비스에 제출
2. 측정: 업로드→완료 총 시간(3회 반복), 출력 품질(잔존/뭉개짐 육안 + 동일 프레임 크롭 비교), 실패율
3. 산출물: COMPETITOR_FULL_BENCHMARK.csv + 프레임 비교 이미지 + 요약 보고
4. 구독 해지: 측정 완료 즉시 해지 안내를 제가 준비, 해지 클릭은 대표가 직접
