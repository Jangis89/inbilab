## 테스트별 상세 (명세 B.4 요구 6종)

### T1 — 폴링 12회+ 동안 60초 연속 재생
처리 중 작업 1개 존재(폴링 유지) 상태에서 완료 카드 영상을 재생, 60초 관찰.
- 체크: 폴링 ≥12회 실행 / video 노드 identity 유지 / 재생 중단 0 /
  currentTime 단조 증가 / AbortError 0
- orig: **실패** (9초 내 노드 교체, AbortError 발생, 재생 초기화 반복)
- fixed: **통과** (폴링 12회+ 동안 동일 노드, 60초 연속 재생)

### T2 — 재생 중 다른 작업 상태 변경
재생 도중 `__mockJobs`의 다른 작업을 wm_running→wm_done으로 변경.
- 체크: 해당 카드는 갱신됨 / 재생 중 카드는 무영향
- orig: **실패** (전체 리렌더로 재생 카드도 파괴)
- fixed: **통과**

### T3 — 완료 카드 여러 개 + 신규 작업 추가
완료 카드 3개 중 1개 재생 중, 새 작업 추가로 폴링 재시작.
- 체크: 신규 카드 정상 추가 / 재생 카드 위치·노드 유지
- orig: **실패**
- fixed: **통과**

### T4 — pause / seek / resume
재생→일시정지→탐색(seek)→재개를 폴링 활성 상태에서 수행.
- 체크: 각 조작 후 상태 보존 / seek 위치 유지(Range 요청 정상)
- orig: **실패** (폴링 시 seek 위치 초기화)
- fixed: **통과**

### T5 — 모바일 뷰포트 (390×844)
모바일 화면 크기에서 T1 축약판 수행.
- orig: **실패** (동일 원인)
- fixed: **통과**

### T6 — 페이지 새로고침 후 재생
reload 직후 완료 카드 재생 + 폴링.
- 양쪽 로드 정상, fixed에서 재생 유지 **통과**.

## 원격 검증의 한계 (정직 고지)

원격 제어 중인 브라우저 창이 화면에 표시되지 않는 상태(`document.hidden=true`)
여서 브라우저가 영상 데이터 다운로드를 보류함 → 운영 화면에서 "픽셀이 실제로
움직이는 재생"은 원격으로 재현 불가. 이 부분은 로컬 하네스 T1(60초 연속 재생,
실제 디코딩 포함)으로 갈음했고, **최종 확인은 대표의 직접 재생 테스트**
(PC + 모바일)로 진행한다.

## 대표 확인 안내 (Phase I)

1. 인비랩 사이트 → 자막·워터마크 제거 → 내 작업에서 완료된 영상 재생.
2. 처리 중 작업이 있는 상태에서(또는 새 영상 하나 올려 처리 중으로 만든 뒤)
   완료 영상을 10초 이상 연속 재생 — 끊김/깜빡임이 없어야 정상.
3. 휴대폰에서도 같은 확인 1회.
