# 카드 un-blend v2 보고서 (RC3 Phase D)

- 날짜: 2026-08-20 · 대상: UAT-02 반투명 카드 (대표 판정 "절대 불통과" 항목)
- 코드: `perf/wm-v32-rc3-restoration-quality` — `_estimate_card_model` / `_card_matte` /
  `_seg_masks_for_region` 카드 pre-pass / `segment_v32` 합성 un-blend

## RC2가 실패한 이유 (Phase B 확정)

RC2는 un-blend를 "감지 vote 주변 ±10초 창"에만 적용했다. 실측 결과 카드는
**영상 0~175초 전체에 상시 존재**(전 프레임 시간축 중앙값에 카드가 선명하게 잔존) —
따라서 대부분 구간은 카드 몸체가 전혀 처리되지 않았다(M3). α=0.50 추정 자체는 정확했다.

## v2 설계 (구현·검증 완료)

1. **전역 카드 모델**: 카드가 확인되면(vote≥2) 영상 전체 통계로 한 번에 모델링
   - rect: 존재 샘플 중앙값 영상에서 부호 고정(안쪽으로 밝아지는) 1-D ridge → un-blend
     후 테두리 에너지 최소화로 미세 정렬 (rounded corner 반경 포함)
   - **α: 시간축 분산비** — 카드 안 밝기 변동은 배경의 (1-α)배.
     UAT-02 실측: 17개 장면 분산비 중앙값 0.511 → **α=0.4979** (반복 재추정 수렴)
   - **C: 경계 인접 픽셀쌍** (in-(1-α)·out)/α 강건 중앙값 → **C≈(253.8, 253.9, 254.1)**
   - 존재 판별: "un-blend가 테두리를 지우면 존재, 만들면 부재" 판별식 → 전 샘플
     타임라인 → **ivals [0, 5265] (전체 175초 커버)** — RC2의 창 한계 제거
   - 커버리지 85%+면 ≤8초 내부 공백 메움 (저대비 장면 hysteresis 미달 보정)
2. **matte**: rounded-rect + 모서리 반경 + feathered AA edge (supersample 4×)
3. **적용**: 존재 구간의 **모든 프레임**에 un-blend (세그 AI 문맥 + 합성 출력 동시)
4. **글자 마스크 3중**: ① 물리 검출(카드 몸체는 α·C≈127보다 어두울 수 없음 —
   어두운 배경에서도 글자 획을 놓치지 않음) ② un-blend 후 국소 중앙값 대비 stroke
   ③ 표준 키프레임 글자 감지. + 테두리 링(±6px) AI 마스크
5. **AI 재도색 금지**: RC2의 정적 합집합 마스크 병합을 제거 — 카드 내부 전체를
   AI가 다시 그리며 배경을 뭉개던 회귀(1차 GPU 실측) 차단
6. **오탐 물리 가드**: 실물(불투명) 물체는 분산비≈1 → α≈0 → 모델 기각.
   α∈[0.30, 0.72] 밖이면 전부 기존 RC2 경로 폴백 (골든 회귀 안전)
