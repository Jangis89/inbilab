### 통합 중 발견·해결한 문제 (정직 기록)
- **RC-T 전량 NaN**: 공식 RC-T는 마스크의 bounding **square**를 잘라 특징맵으로
  내린 뒤 sliding window마다 교집합 화소 ≥5일 때만 유효창으로 센다. 자막처럼
  600×60짜리 가는 띠는 600×600 정사각 안에서 특징맵 1~2셀로 줄어 **모든 창이
  기준 미달** → g26에서 79쌍 전부 NaN.
  → **공식 계산식은 불변**, 논문이 RC-S에서 이미 쓰는 "target 단위 평가"를
  RC-T에도 적용해 띠를 정사각 타일로 분할(폭≈3×높이). 재실행 결과 NaN 0건.
- **PROVE의 한계 발견**: RC-S/RC-T는 "자연스러움·일관성"은 잘 재지만
  **읽히는 글자잔상과 카드 잔존을 못 잡는다.** 실제로 PROVE 상위 후보가
  카드 자막 구간에서 카드를 그대로 남기는 사례가 확인됐다.
  → 명세 §11.2의 **필수 탈락 1·2순위**(읽을 수 있는 글자잔상 / 카드 ghost)를
  객관 계측하는 보조지표 2종을 신규 제작·합성검증 후 전 구간 측정
  (`docs/RC4_GLYPH_CARD_RESIDUAL.csv`).
