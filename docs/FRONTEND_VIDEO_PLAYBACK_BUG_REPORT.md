# 운영 프론트 영상 재생 끊김 버그 리포트 (RC2 Phase B)

- 날짜: 2026-08-19
- 파일: `watermark-remover.html` (운영, Vercel 자동 배포)
- 증상 (대표 보고): 결과 영상 재생 버튼을 누르면 2~3초만 재생되고 끊기며 화면이 깜빡임.
  특정 영상이 아니라 모든 영상에서 재발.
- V32 GPU 파이프라인과 무관한 **순수 프론트엔드 버그** (별도 커밋으로 수정).

## 1. 원인 (확정 — 실측 근거 포함)

작업 목록(내 작업)은 `listMine()` 함수가 5초마다 서버에서 작업 상태를 받아와
화면을 다시 그린다(폴링). 처리 중인 작업이 하나라도 있으면 폴링이 계속 도는데,
이때 두 가지 동작이 재생 중인 영상을 파괴했다.

### 원인 1 — 완료 카드를 매번 새로 그림
```js
// 기존 코드 (updateRow 안)
if(st==="wm_done"){
  ...
  done.innerHTML = '<video controls ...>';   // 5초마다 <video>를 새로 만듦
}
```
5초마다 `innerHTML`로 `<video>` 태그를 통째로 갈아끼우므로,
재생 중이던 video 요소가 문서에서 제거되고 새 요소로 교체된다.
→ 재생이 끊기고 처음부터 다시 로드(깜빡임).

### 원인 2 — 재생 중인 카드를 목록 재정렬로 이동
```js
// 기존 코드 (listMine 안)
arr.forEach(function(p){ ...; $id("worklist").appendChild(w); ... });
```
`appendChild`는 이미 문서에 있는 노드를 **떼어내서 다시 붙인다**.
HTML 규격상 video 요소는 문서에서 떨어지는 순간 재생이 중단된다.
→ 5초마다 모든 카드가 이동하며 재생 중이던 영상도 끊김.

### 실측 증거 (수정 전 운영 코드)
- 브라우저 콘솔에 `AbortError: The play() request was interrupted because
  the media was removed from the document.` 실제 발생 확인.
- 재생 시작 후 9초 이내에 video DOM 노드가 다른 노드로 교체되는 것을
  노드 identity 추적으로 실측.

## 2. 영향

- 처리 중 작업이 1개라도 있으면(폴링 활성) 완료된 결과 영상을 5초 이상
  연속 재생할 수 없음 → 대표/고객이 결과물을 확인 불가 수준.
- 데이터 손상 없음. 영상 파일 자체는 정상 (재생 UI 문제만).

## 3. 수정 (2곳, 최소 변경)

### 수정 1 — 완료 카드는 한 번만 그린다
```js
if(st==="wm_done"){
  if(w.dataset.doneRendered==="1") return;   // 이미 그렸으면 건너뜀
  w.dataset.doneRendered="1";
  ...
}
```
완료 상태는 더 바뀔 일이 없으므로 최초 1회만 그리면 충분하다.

### 수정 2 — 재생 중인 카드는 자리 이동을 생략한다
```js
var vv=w.querySelector("video"), playing=vv&&!vv.paused&&!vv.ended;
if(!w.parentNode||!playing) $id("worklist").appendChild(w);
```
새 카드이거나 재생 중이 아닐 때만 정렬 이동. 재생 중이면 현재 자리 유지.

### 명세 금지사항 준수
- `play().catch()`로 오류를 숨기지 않음 — 원인 자체를 제거.
- 폴링은 그대로 유지 (진행 중 작업 상태 갱신 기능 보존).
- V32 GPU 코드와 섞지 않은 프론트 단독 커밋 → 문제 시 이 커밋만 revert 가능.

## 6. 한계 (정직 고지)

원격 검증 환경에서는 브라우저 창이 화면에 보이지 않는 상태라 브라우저가
영상 데이터 로딩 자체를 보류하는 정책이 있어, **픽셀이 실제로 움직이는
연속 재생**까지는 원격으로 확인할 수 없었다. 다만 이 버그의 원인(폴링이
재생 중 video 노드를 파괴)은 DOM 수준에서 제거가 실측 확인되었고, 실제
재생 유지는 로컬 하네스의 60초 연속 재생 테스트(T1)로 검증했다.
**대표가 직접 PC/모바일에서 재생 확인하는 것이 최종 판정**이며, 명세
Phase I에 따라 확인을 요청한다.
