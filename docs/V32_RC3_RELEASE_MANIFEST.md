## 성공 기준 재정의 이행

RC2 "글자가 지워졌는가" → RC3 **"정상속도 재생에서 지운 자리가 원래처럼 자연스러운가"**.
Detection / Restoration 분리 진단(Phase B Oracle) → 복원 파이프라인 재설계.

## RC3에서 만든 것 (구현 완료)

1. **전역 카드 모델**: 시간축 분산비 α(실측 0.4979) + 경계쌍 C(≈254) + 1-D 부호 ridge
   기하 + un-blend 최소화 미세정렬 + 존재판별 타임라인 → **전 구간 un-blend**
   (RC2의 vote±10초 창 한계 제거). 정적 장면 폴백(경계쌍 회귀) 포함.
2. **물리 글자마스크**: 카드 몸체는 α·C(≈127)보다 어두울 수 없음 → 어두운 획만
   정밀 마스크. 배경 오발 0 (개·바구니 재도색 회귀 3종 차단: 표준 스윕 생략,
   box 경로 차단, stroke 폴백 강등).
3. **tight paste**: AI 입력은 시간합집합, 출력 붙임은 현재 프레임 글자 자리만 —
   비용 0으로 얼룩 면적 축소.
4. **crop-HQ 라우팅**: 질감 위험(링 |lap|≥3) + 면적≤0.70 + 비용비≤1.7× 조건에서만
   마스크 주변 원해상 복원 (전 영상 HQ 강제 없음 — G.1 준수).
5. **국소 색 정합**: AI 결과의 링 기준 색 드리프트 보정(±15).
6. **복원 품질 평가체계**: evaluate_restoration_quality.py + 골든 g26~g35(전부 clean
   GT/control) + GT-aware 잔존획 지표 + gt-restore 게이트(1차 분포 고정).
